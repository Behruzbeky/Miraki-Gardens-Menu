# Miraki Gardens — меню для планшетов

- Меню для гостей: `https://behruzbeky.github.io/Miraki-Gardens-Menu/`
- Админ-панель: `https://behruzbeky.github.io/Miraki-Gardens-Menu/admin.html`

## Что умеет админ-панель

- менять названия и описания блюд на трёх языках (RU / UZ / EN), цену и порцию;
- загружать и менять фото (с телефона, планшета или компьютера — фото сжимается само);
- добавлять и удалять блюда, переносить блюдо в другую категорию;
- менять порядок блюд и категорий стрелками ▲▼;
- **стоп-лист**: переключатель у блюда скрывает его с планшетов, не удаляя;
- добавлять, переименовывать, скрывать и удалять категории, выбирать значок;
- менять примечание о ценах (⚙ → «Примечание под названием категории»).

Все правки сначала сохраняются как черновик на этом устройстве (статус «Есть неопубликованные изменения»).
Гости увидят их только после кнопки **«Опубликовать»**. Планшеты подтянут новое меню сами за 1–10 минут —
перезагрузка происходит, только когда в корзине пусто, чтобы не сбить заказ гостя.

## Первый вход (делает владелец сайта один раз на каждом устройстве админа)

1. Войти в GitHub-аккаунт, которому принадлежит репозиторий `miraki-gardens-menu`.
2. Открыть https://github.com/settings/personal-access-tokens/new
3. Token name: `Miraki menu admin`, Expiration: 1 год (или No expiration).
4. Repository access → **Only select repositories** → `miraki-gardens-menu`.
5. Permissions → Repository permissions → **Contents: Read and write**.
6. **Generate token**, скопировать ключ `github_pat_…` и вставить на странице `admin.html`.

Ключ хранится только в браузере этого устройства. Выйти и удалить ключ: ⚙ → «Выйти».
Если ключ утёк или сотрудник уволился — удалите токен на той же странице GitHub, и он перестанет работать.

## Как это устроено

- `menu-data.js` — всё содержимое меню (JSON после `window.MENU =`). Админ-панель переписывает этот файл.
- `images/` — фото. Новые фото получают уникальные имена, старые файлы не удаляются.
- `admin.html`, `admin.js`, `admin.css` — админ-панель. Сохраняет изменения коммитом в ветку `main` через GitHub API.
- `sw.js` — офлайн-режим: меню и скрипты берутся из сети (с запасной копией в кэше), фото — из кэша.
- Поле `"hidden": true` у блюда или категории — не показывать гостям.
