# Miraki Gardens — меню для планшетов

- Меню для гостей: `https://behruzbeky.github.io/Miraki-Gardens-Menu/`
- Админ-панель: `https://behruzbeky.github.io/Miraki-Gardens-Menu/admin.html`

## Что умеет админ-панель

- менять названия и описания блюд на трёх языках (RU / UZ / EN), цену и порцию;
- загружать и менять фото (с телефона, планшета или компьютера — фото сжимается само);
- добавлять и удалять блюда, переносить блюдо в другую категорию;
- менять порядок блюд и категорий стрелками ▲▼;
- **стоп-лист**: переключатель у блюда скрывает его с планшетов, не удаляя;
- добавлять, переименовывать, скрывать и удалять категории, выбирать значок;
- менять примечание о ценах (⚙ → «Примечание под названием категории»).

Все правки сначала сохраняются как черновик на этом устройстве (статус «Есть неопубликованные изменения»).
Гости увидят их только после кнопки **«Опубликовать»**. Планшеты подтянут новое меню сами за 1–10 минут —
перезагрузка происходит, только когда в корзине пусто, чтобы не сбить заказ гостя.

## Вход

Вход по паролю (пароль выдаёт владелец). На устройстве он запоминается, выйти можно через ⚙ → «Выйти».
После 10 неверных паролей с одного адреса вход блокируется на 15 минут.

## Как это устроено

- Живое меню и новые фото хранятся в Supabase: таблица `miraki_menu`, хранилище фото `miraki-menu-photos`,
  функция `menu-admin` (отдаёт меню, проверяет пароль и сохраняет изменения). Адрес — в `cloud-config.js`.
- Сменить пароль: Supabase → Edge Functions → Secrets → `MIRAKI_ADMIN_PASSWORD`.
- Планшеты берут меню из облака, запоминают его и проверяют обновления каждые 2 минуты
  (перезагрузка только при пустой корзине). Без интернета работают на последней сохранённой версии.
- `menu-data.js` — исходное меню, используется только при самом первом запуске без интернета.
- `images/` — исходные фото; новые фото из админки лежат в облаке.
- Поле `"hidden": true` у блюда или категории — не показывать гостям.
